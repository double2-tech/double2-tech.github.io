# Вьюер моделей IFC4 RV

Статическая публикация на GitHub Pages. Сервер не нужен: браузер скачивает
предразобранный пакет `.rvpack` и рисует его сам.

## Что лежит в репозитории

```
index.html              вьюер, публичная сборка
.nojekyll               отключает обработку Jekyll — без него Pages ломает файлы
.gitattributes          .rvpack не трогать переводами строк
.gitignore              .ifc в репозиторий не попадают
models/
  models.json           список моделей
  *.rvpack              сами модели
publish.cmd             залить изменения одним двойным кликом (Windows)
```

## Первая публикация

1. Создать на GitHub пустой репозиторий, например `bim-viewer`.
2. Скопировать в него содержимое этой папки.
3. Положить свой `.rvpack` в `models/` и прописать его в `models/models.json`.
4. Отправить:

   ```bash
   git init
   git add -A
   git commit -m "первая версия"
   git branch -M main
   git remote add origin https://github.com/ЛОГИН/bim-viewer.git
   git push -u origin main
   ```

5. В репозитории: **Settings → Pages → Source: Deploy from a branch**,
   ветка `main`, папка `/ (root)`. Сохранить.

Через минуту-две сайт открывается по адресу
`https://ЛОГИН.github.io/bim-viewer/`.

## Обновить модель

Положить новый `.rvpack` в `models/`, поправить `models.json`, запустить
`publish.cmd` — или вручную `git add -A && git commit -m "..." && git push`.

Имя файла лучше версионировать датой: `facade-2026-05.rvpack`. Тогда у тех,
кто уже открывал старую версию, не останется её в кеше браузера.

## models.json

```json
{
  "default": "facade_V3_demo",
  "models": [
    { "id": "facade_V3_demo", "name": "Фасад, корпус А", "url": "facade_V3_demo.rvpack" }
  ]
}
```

`id` — любой, он же попадает в ссылку. `url` — путь относительно
`models/models.json`. `default` — что открывается без параметров.

Если модель одна, выпадающий список в панели не показывается. При нескольких
моделях появляется переключатель, а прямая ссылка на конкретную выглядит так:

```
https://ЛОГИН.github.io/bim-viewer/?model=facade_V3_demo
```

Идентификатор, которого нет в манифесте, игнорируется — открыть чужой файл
через адресную строку нельзя.

## Ограничения GitHub

| Что | Предел |
|---|---|
| Размер одного файла | 100 МБ жёстко, предупреждение с 50 МБ |
| Размер сайта | 1 ГБ |
| Трафик | 100 ГБ в месяц, мягкий |

Git LFS использовать нельзя: Pages отдаёт вместо файла текстовый указатель.
Если пакет не помещается — Cloudflare Pages вместе с R2 либо обычный VPS.

## Подготовка новой модели

Публичная сборка не умеет открывать `.ifc` — это сделано намеренно. Пакеты
собираются локальной сборкой вьюера (`SHOW_ADMIN = true`): открыть `.ifc`
с диска, нажать «Собрать .rvpack», согласиться на чтение наборов свойств,
чтобы они уехали внутрь пакета.
